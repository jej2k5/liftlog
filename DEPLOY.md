# Publish Lift Log to GitHub Pages

The complete app is committed to this repository. To make it live:

1. Open https://github.com/jej2k5/liftlog/settings/pages
2. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
3. Set branch **main**, folder **/(root)**, and select **Save**.
4. When GitHub displays the published site, open https://jej2k5.github.io/liftlog/ on your iPhone in Safari.
5. Select **Share → Add to Home Screen** to install it.

The website is public because the repository is public. Actual workout logs remain in your device's browser local storage. Export backups regularly; iOS Safari and home-screen app storage may be separate.
