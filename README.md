# Lift Log | 5/3/1 + Mansour Method Strength Accessories

Mobile-first, offline-capable four-day workout tracker. Primary lifts follow 5/3/1 using editable calculated 1RMs and conservative training maxes. A bench-priority supplement focuses on better pressing technique and control through the midpoint.

## Four-day plan

| Day | 5/3/1 primary | Mansour strength accessories (original PDF page) |
| --- | --- | --- |
| Monday | Bench | Chest, p. 10: wide-grip barbell incline press, flat DB press, incline DB flyes, cable flyes, weighted dips |
| Tuesday | Deadlift | Back/biceps, p. 11: standard/lateral/underhand pull-ups, wide-grip BB row, single-arm DB row, hammer curls, standing EZ-bar curls, cable rope curls |
| Thursday | Overhead press | Shoulders/triceps, p. 12: behind-the-neck press, Bradford press, shrugs, lateral raises, bent-over rear-delt flyes, close-grip bench, DB skullcrushers, cable pushdown |
| Saturday | Squat | Legs, p. 9: adductors, abductors, pause squats, Romanian deadlifts, Bulgarian split squats, leg extensions, calf raises |

The source PDF is **The Mansour Method** by Ziad Mansour, strength routines on pages 9–12. Main-lift warm-up / working sets from that document have been replaced with 5/3/1, not duplicated.

## Accessory modes

- **Focused hybrid** (default): reduced accessory sets selected for this bench-priority 5/3/1 block. These set prescriptions are custom adaptations and **not** the author's original prescriptions.
- **Full Mansour strength accessories**: original accessory set and repetition prescriptions from the PDF (high volume). Use selectively; completing all the source work on top of 5/3/1 is not recommended by this app.

Open each workout's **Browse all Mansour accessories** section to add or remove specific movements for that one session. Completed workouts, set weights, actual reps, RPE and notes are stored in the browser. Choices for other weeks are unaffected. Previously logged exercises from the old app remain accessible as legacy history when present.

Bench-specific **paused bench** on Thursday and **bench volume** on Saturday are explicitly labeled as extra exercises, not source-PDF Mansour work.

### Training max starting settings

| Lift | User-reported calculated 1RM (lb) | Starting TM (lb) |
| --- | ---: | ---: |
| Bench | 190 | 140 conservative override |
| Squat | 295 | 250 (85% rounded) |
| Deadlift | 320 | 270 (85% rounded) |
| Overhead press | 140 | 120 (85% rounded) |

The bench TM override follows a recent 155-lb set with an assisted third rep. Modify targets based on performance, not on the calculated 190-lb estimate. 5/3/1 + sets are capped at clean reps (about RPE 8); no forced max tests.

## Install on iPhone

1. Enable [GitHub Pages](https://github.com/jej2k5/liftlog/settings/pages): Deploy from branch **main**, folder **/(root)**.
2. Open https://jej2k5.github.io/liftlog/ in Safari.
3. Tap **Share → Add to Home Screen**.

Data is stored in local browser storage only. It does not automatically sync between Safari and the installed web app or across devices. Export JSON backups before changing browser, clearing site data, or changing accessory modes. Reload online once after deployment to get the updated app/service worker.

**Safety:** This is a training tracker, not a medical prescription. Keep sets short of failure and avoid grinding or prolonged breath-holding. With cardiovascular risk concerns, obtain clinician guidance before maximal testing. Behind-the-neck pressing and weighted dips are optional and depend on suitable joint tolerance.
