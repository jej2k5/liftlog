# Lift Log | 5/3/1 Strength Tracker

A static, mobile-first four-day strength training tracker combining 5/3/1 for the primary lifts with a modified Mansour Method accessory selection and additional bench practice.

## Program

- **Monday:** 5/3/1 bench press, rows and close-grip bench
- **Tuesday:** 5/3/1 deadlift, split squats and core
- **Thursday:** 5/3/1 overhead press, light paused bench and lat pulldowns
- **Saturday:** Bench volume, 5/3/1 squat and triceps

Weeks 1–3 use 5/3/1 percentage schemes (65/75/85, 70/80/90, 75/85/95 of **training max**). Week 4 is a deload (40/50/60). Week 5 begins the next cycle only if appropriate.

## Current starting values (editable in Settings)

| Lift | User-reported calculated 1RM (lb) | Initial training max (lb) |
| --- | ---: | ---: |
| Bench | 190 | 140 (deliberate safety override) |
| Squat | 295 | 250 |
| Deadlift | 320 | 270 |
| Overhead press | 140 | 120 |

The bench safety override reflects a more recent 155-lb set where the third rep required assistance. Other maxes are estimates; reduce the prescribed load if the first week exceeds target effort. The user can change the estimated maxes, training-max percentage (80/85/90) and bench override in Settings.

A + set means **optional additional clean reps**, never technical failure. Week 5 adds 5 lb to upper-body training maxes and 10 lb to lower-body training maxes only if the preceding cycle was successful. Disable this option in Settings if you need to repeat your TM.

## Installation

1. Enable [GitHub Pages](https://github.com/jej2k5/liftlog/settings/pages): Deploy from a branch > main > / (root).
2. Open https://jej2k5.github.io/liftlog/ in iPhone Safari.
3. Choose **Share > Add to Home Screen**.

Data stays in browser localStorage. Export JSON backups from Settings before changing devices, clearing browser data, or using a different browser. The PWA caches app resources for offline use after first successful HTTPS load.

**Safety:** Keep most sets at RPE 7–8 or below, avoid assisted reps or prolonged breath-holding, and consult a clinician before maximal testing if cardiovascular risk concerns are relevant.
