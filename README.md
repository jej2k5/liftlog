# Lift Log — Mobile Workout Tracker

A self-contained, static, mobile-first app for a bench-priority five-week strength program. It includes all four training days, set tracking, RPE and notes, rest timer, progress dashboard, and export/import of workout data.

## Use on iPhone

Once GitHub Pages is enabled for this repository, open https://jej2k5.github.io/liftlog/ in iPhone Safari and choose **Share → Add to Home Screen**.

### Enable Pages

Visit this repository's **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/(root)**, and Save.

Your completed workouts and notes live in this browser's local storage, not in GitHub. They do not sync between devices. Back up from **Settings → Export backup** and use **Import backup** to restore. Clearing Safari/website data may remove locally stored workout logs.

The web app works offline after its first successful HTTPS load, once its service worker has cached the files. Workout plan weights are targets, not mandatory increases. Do not attempt a maximal bench test without appropriate clearance and safety equipment.
